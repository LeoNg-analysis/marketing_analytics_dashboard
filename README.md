📊 Marketing Analytics Dashboard — Power BI

An interactive Power BI dashboard analyzing multi-channel marketing performance for Voltex Innovation across Facebook, Instagram, and Pinterest from March to November 2023.

🎯 Project Objectives
- Track and compare marketing performance across 3 paid channels (Facebook, Instagram, Pinterest)
- Identify top-performing and underperforming campaigns, ad types, and regions
- Provide actionable insights to support marketing budget optimization decisions

📌 Key Insights
- Pinterest is the most efficient channel with a ROAS of 21.47x and the lowest CPA at £2.45
- Summer – Discount campaigns delivered the highest conversion value across all channels
- Birmingham outperforms the average conversion rate by +30%, while London underperforms by -21%
- Several Fall and Spring campaigns on Facebook and Instagram are flagged as underperforming (ROI < avg), indicating budget reallocation opportunities
- Overall: £163K total spend generated 40K conversions with an ROI of 9.61x

📊 Dashboard Pages
Page	Description
- Overview	High-level KPIs: Total Spend, ROI, ROAS, Total Conversions and trend over time
- Channel	Channel-by-channel breakdown: CR, CPA, CTR, ROAS, and campaign performance
- Geography	Regional comparison across Birmingham, London, and Manchester with efficiency matrix

🛠️ Tools & Skills Used
- Tool	Purpose
- Power BI	Dashboard design and interactive visualization
- DAX	Custom measures — ROI, ROAS, CPA, CTR, Conversion Rate
- Power Query	Data cleaning and transformation

📂 Dataset
Source: Maz Data Vietnam
Period: March 2023 – November 2023
Dimensions: Channel, Campaign (Fall / Spring / Summer), Ad Type (Collection / Discount), Device, Region
Metrics: Total Spend, Conversion Value, Conversions, Impressions, Clicks
